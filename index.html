    ABOUT PDFMASTER

    Free Online PDF & Image Tools

    PDFMaster brings useful PDF and image utilities together in one place. Use the Photo to PDF tool to turn JPG and PNG images into a PDF, combine documents with Merge PDF, or extract and remove pages with Split PDF. You can also reduce PDF and image file sizes, and add password protection to supported PDF files. The tools run in your web browser, so there is no desktop software to install.

    HELP CENTER

    Frequently Asked Questions

    1. Is PDFMaster free to use?

    Yes. PDFMaster's available PDF and image tools are free to use. You can access the tools directly through your web browser.

    2. Can I merge multiple PDF files?

    Yes. Open the Merge PDF tool, select multiple PDF files and click Merge PDF. Your selected documents will be combined into one PDF file.

    3. Can I convert photos into PDF?

    Yes. Open Photo to PDF, select your JPG or PNG images and click Convert to PDF. Your selected images will be placed into a PDF document.

    4. Can I extract or remove PDF pages?

    Yes. The Split PDF tool provides two modes. Choose Extract Selected Pages to keep only selected pages, or Remove Selected Pages to remove selected pages and keep the rest.

    5. Can I compress PDF files?

    Yes. Select a PDF file and choose a compression level. Basic mode aims to preserve text, while Recommended and High modes may convert pages into images. The final file size can vary.

    6. Can I protect PDF files with a password?

    Yes. Select a PDF, enter a password and confirm it before using the Protect PDF tool. Keep your password safe because PDFMaster cannot recover a forgotten password.

    7. Can I compress images?

    Yes. Select JPG, PNG or WebP images using Image Compressor. Adjust the quality and choose an output format before downloading the compressed images.

    8. Do I need to install any software?

    No installation is required. You can open PDFMaster in a supported web browser and use the available tools online.

    9. Are my uploaded files stored on PDFMaster?

    PDFMaster's tools are designed for browser-based processing. However, external libraries and network resources may be loaded by the website. Avoid using sensitive documents unless you have reviewed the Privacy Policy and understand how the tools work.

    10. What should I do if a tool does not work?

    First, check that you have selected a supported file format and that your browser is up to date. You can refresh the page and try again. If the problem continues, contact our support team through the Contact Us page.
