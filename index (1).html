1. Getting Started

What is PDFMaster?

PDFMaster is a browser-based toolkit for common PDF and image tasks. It currently provides six tools: Photo to PDF, Merge PDF, Split PDF, Compress PDF, Protect PDF and Image Compressor.

How do I use PDFMaster?

Open the tool you need, select a supported file from your device, choose any available settings and click the action button. Wait for processing to finish, then use the download option provided by the tool.

Do I need to install software?

No separate desktop application is required. You can use the website through a supported web browser. An internet connection is needed to load the website and its external libraries.

Can I use PDFMaster on a phone or computer?

The website has a responsive layout intended for mobile and desktop screens. The experience and processing capacity can vary depending on your browser, device memory and file size.

Are PDFMaster tools free?

The tools currently offered on PDFMaster are presented as free to use. Any future changes to availability or features will be reflected on the website.

2. Photo to PDF Guide

How do I convert photos into a PDF?
  1. Open the Photo to PDF tool.
  2. Select one or more JPG or PNG images from your device.
  3. Review the selected images in the file list.
  4. Click Convert to PDF.
  5. When processing finishes, download the generated PDF.
Can I convert multiple photos into one PDF?

Yes. Select multiple supported JPG or PNG images together. The tool combines the selected images into one PDF. Review your selection before starting the conversion.

Which image formats does Photo to PDF accept?

The file selector is configured for JPG and PNG images. Other formats may not be accepted by this tool.

What does Clear All do?

Clear All removes the current selection from the tool so you can begin again. It is not intended to delete the original image files stored on your device.

3. Merge PDF Guide

How do I merge PDF files?
  1. Open the Merge PDF tool.
  2. Select the PDF documents you want to combine.
  3. Review the selected files in the list.
  4. Click Merge PDF.
  5. Download the combined PDF after processing completes.
How many PDF files should I select?

The tool is intended to combine multiple PDF documents. Select at least two PDF files for a merge operation.

Will merging delete my original PDFs?

The merge operation creates a separate output document. It is not intended to delete the original files stored on your device. Keep your own backup of important documents.

4. Split PDF Guide

How do I split a PDF?
  1. Open the Split PDF tool and select a PDF.
  2. Choose either Extract Selected Pages or Remove Selected Pages.
  3. Enter the page numbers or ranges in the page field.
  4. Check that the page numbers exist in your document.
  5. Click Split PDF and download the resulting file.
What does Extract Selected Pages mean?

Extract Selected Pages creates a new PDF containing only the pages you specify. For example, 1-3, 5 selects pages 1, 2, 3 and 5 for the new document.

What does Remove Selected Pages mean?

Remove Selected Pages creates a new PDF that excludes the pages you specify and keeps the remaining pages. For example, selecting 2, 4-5 removes pages 2, 4 and 5 from the output.

How should I enter page numbers and ranges?

Use commas to separate individual pages or ranges. Examples:

  • 1 — page 1 only.
  • 2, 5, 8 — pages 2, 5 and 8.
  • 1-3 — pages 1 through 3.
  • 1-3, 5, 7-9 — pages 1, 2, 3, 5, 7, 8 and 9.

Page numbering starts at 1. Do not enter page numbers that are outside the document's page count.

5. Compress PDF Guide

How do I compress a PDF?
  1. Open Compress PDF.
  2. Select the PDF file you want to process.
  3. Choose Basic, Recommended or High.
  4. Click Compress PDF.
  5. Wait for processing, then download the output file.
What is Basic compression?

Basic mode is intended to preserve text-based PDF content. Depending on the source document, it may provide a smaller reduction in file size than the other modes.

What is Recommended compression?

Recommended mode aims to balance output size and appearance. The tool notice explains that this mode converts pages into images, so selectable text, links and forms may not be preserved.

What is High compression?

High mode aims for a smaller output file. It also converts pages into images, so selectable text, links and forms may not be preserved. Review the result before relying on it.

Will every PDF become smaller?

No. Results depend on the original file, its images, content and selected mode. Some files may show only a small reduction or may not become smaller.

6. Protect PDF Guide

How do I protect a PDF with a password?
  1. Open Protect PDF and select a PDF file.
  2. Enter a password in the Create Password field.
  3. Enter the same password in Confirm Password.
  4. Check that both entries match.
  5. Click Protect PDF and download the protected file when ready.
Why do I need to enter the password twice?

The confirmation field helps catch typing mistakes. The password in both fields must match before the tool can proceed.

What password length is accepted?

The current form specifies a minimum of 8 characters and a maximum of 128 characters. Choose a password that is difficult to guess and keep it somewhere secure.

What if I forget my PDF password?

PDFMaster cannot recover a forgotten password. Keep a secure record of it before protecting an important document. Do not protect a file unless you can safely retain the password.

7. Image Compressor Guide

How do I compress images?
  1. Open Image Compressor.
  2. Select one or more JPG, PNG or WebP images.
  3. Adjust the Compression Quality slider.
  4. Choose an output format.
  5. Click Compress Images.
  6. Download the compressed image output.
What does the Compression Quality slider do?

The slider provides a setting from 10% to 100%. Lower quality settings can reduce file size but may make visible image detail less clear. Higher settings generally retain more visual detail and may produce larger files.

Which output formats are available?

The selector offers Keep Original Format, JPG, WebP and PNG. The result depends on the selected format and the source image.

Which format should I choose?

JPG is commonly used for photographs. PNG is useful when lossless output or transparency is important. WebP is a modern format that can offer efficient compression. Choose according to how you plan to use the image.

Will compressing an image delete my original?

The tool is intended to create a compressed output file rather than delete your original image. Keep a separate backup of important images.

8. Troubleshooting

Why is my file not being selected?

Check that the file type is supported by the selected tool and that the file is available on your device. Try selecting it again. A damaged or unsupported file may not load correctly.

Why is processing taking a long time?

Processing time can depend on file size, page count, image resolution, browser performance and available device memory. Large files may take longer. Avoid closing the page while a task is running.

Why am I seeing a processing error?

The file may be damaged, unsupported or too demanding for the available browser resources. Try another valid file. If the problem continues, refresh the page and try a smaller file.

Why is my download not starting?

Check whether your browser is blocking downloads, whether a download prompt is waiting for permission and whether your device has enough storage. You can also try again in an updated browser.

What should I do if a tool stops responding?

Give the operation a little time. If it remains unresponsive, refresh the page and try again with a smaller file. Keep your original document so you can repeat the task if necessary.

9. Privacy & Security

Does PDFMaster upload my files to a server?

The tools are designed for browser-based processing. However, the website also loads external libraries and other web resources. Read the Privacy Policy for the current explanation of data handling. Do not assume that every network connection made by a website is offline or private.

Are my original files changed?

The tools are intended to generate output files rather than overwrite the original files on your device. Still, keep your own backup of important documents before processing them.

Can PDFMaster recover my password?

No. PDFMaster cannot recover a forgotten password for a protected PDF. Keep your password in a safe place.
